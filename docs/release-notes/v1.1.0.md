**Internal refactor in preparation for the multi-instrument hub.** No change
to results, reports or behaviour: golden tests pin every output value to
v1.0.0.

- The distillation can now be run for one sample without writing the results
  CSV or moving the CDF (`distill.compute()`), with the calibration settings
  passed in rather than read from the global settings. The watcher, reprocess
  and Export to LIMS still go through `process_cdf`, which now wraps it.
- Synthetic chromatogram fixtures and golden rows
  (`tests/golden/d2887_rows.json`) were captured from v1.0.0 before the
  change; the tests fail if any value differs.
