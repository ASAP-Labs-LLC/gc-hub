**First deployable release of GC Hub.** It is installed and updated on ASAPSV1
by the same updater as COA Reviewer; first-time setup is in `DEPLOY.md`.

- **Calibration crash fixed.** Analysis, Export Report and the QBench export no
  longer fail with the 9/16 calibration file.
- **Carbon labels come from the saved calibration assignments**, the same
  source the distillation uses, so ignored peaks (CS2, impurities) never get
  a carbon number.
- **D2887 results can change** for calibrations whose saved assignments
  contain duplicate, unknown or out-of-order carbons. Those entries are now
  dropped consistently from both the distillation calibration and the labels.
- **Results CSV rewrites are atomic.** A restart or crash mid-write can no
  longer leave `distill_results.csv` truncated.
- **QBench API credentials are entered in Settings > QBench API** (tested
  before they are saved) instead of being built into the code.
