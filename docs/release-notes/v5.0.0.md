## Results, Settings and Help

**Results** (sidebar, `/results`) shows every run's D2887 and D86 temperatures side by side, under one "D2887 (°C)" and one "D86 (°C)" heading. The headings come from the hub's own column list, so each one sits over its own numbers (the old Distillation Data tab once had them swapped).
- **Key points** (IBP, 10 %, 50 %, 90 %, FBP) by default; **All points** shows every cut, the fit score and the source file. The choice is remembered on this computer.
- Filter by lab ID, GC, time (today, last 7/30/90 days), status (final, held, error, processing) and Flagged. The filters are in the address, so a filtered view can be bookmarked or sent, and Back and Forward work.
- Each run shows its status as a mark and, when it is not final, why. Backfill runs are labelled. Numbers are right-aligned with one decimal; hover for two.
- **Corrected D86** works as before: on, the numbers written to the results file (with the GC's correction factors); off, the conversion before them. 40 % and 60 % are midpoints and say so when you hover them.
- A run's lab ID opens its data view. Tick up to six runs to draw their distillation curves on one chart (drag to zoom, double-click to reset).
- **Download CSV** saves the runs the filters show, with every cut, as shown (corrected or not).

**Settings** (user menu, `/settings`) replaces the old Settings window, grouped by who changes what:
- *This browser*: the theme, and whether Results shows D86 with correction factors first.
- *Sample flags*: the flag rules, for anyone.
- *Best fit*, *Findings*, *Compare defaults*, *Comparison standards* (tag with a GC, rename, delete, add from a run's lab ID) and the *LEM address*: these ask for the admin password once, in the masked dialog, and keep it in the tab for 15 minutes. No more password boxes that show what you type.
- *QBench*: the API key (admin; checked with QBench before it is saved) and which web login uploads use.
- *Server*: where the hub keeps things, read-only and folded away. The old watch folder, processed-CDF folder and results CSV fields (unused since v2) are gone.

**Restart** moved to Admin · Server, with the same "Restart & install vX" when an update is staged and the same warning when work would be cut short.

**Help** (user menu, `/help`) is one short page in plain words, brought up to date (per-GC correction factors, the hub, the marks).

**Notifications**: the bell opens a panel listing what needs a person, newest first, each with its level in words, when it came, and a link to where it is fixed. Dismiss one or all. New ones appear without a refresh.

None of this changes a result, report, CSV or export.
