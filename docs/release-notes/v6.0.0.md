**v6.0.0: a one-page report in the app's look, conclusion presets, upload retry, stacked chromatograms, phones and tablets, and the bugs from the v5 Samples page.** This is a MAJOR release because the report PDF and the Samples page display results differently. No D2887/D86 number is calculated, stored or exported differently. The results CSV LEM reads and Export to LIMS are unchanged.

## Upgrading from v5.1.0

- Install as usual with Admin · Server > "Restart & install v6.0.0". Restart waits for any running upload, import or other background work.
- **No database change.** Rolling back to v5.1.0 is safe.
- **The classic page is gone**, as v5.0.0 announced. Old links redirect: `/classic` → `/`, `/classic/lab/<id>` → `/lab/<id>`, `/classic/samples/<id>[/compare|/data]` → the same run and view, `/instruments/classic` → `/instruments`. Comparison Export, `/api/export-pdf` and the classic reprocess preview routes are removed.
- Open pages ask to reload after the update. Everyone keeps their sign-in. No agent reinstall.

## The report

- **One Letter page, always.** The report is redesigned to match the GC app: dark ink type on white, section titles on the left with hairline rows, colour only for the deviation fill and severity tags. The charts are drawn like Compare's (the standard a light grey area, the sample an ink line, range bands, carbon numbers on the top axis, the difference filled red above and blue below).
- **Order:** the header (document, the standard, lab ID, date), Trend, Difference, Findings (each with its severity tag), Marked regions, the Conclusion (with any earlier notes under it), then Parameters, Ranges and the version.
- **It never spills onto a second page.** When there is a lot to print, the charts shrink first, then the text size, then long lists end with "N more … are in the GC hub". A conclusion of up to 1,500 characters always prints in full.
- Fonts are local (Segoe UI on the server, else Arial), so ≥ and − no longer print as boxes.

## Comments are now conclusions

- **One thing to write: the Conclusion.** On Compare, the Conclusion has **Insert preset**, which adds a preset to the conclusion text for you to edit. The separate Comments box is gone.
- **The conclusion is limited to 1,500 characters**, with a live counter. A paste is cut to fit, with a note; every export, ZIP and QBench upload checks the limit too.
- **Presets are "Conclusion presets"** on Hub admin (the same list as before).
- **Nothing is lost:** comments written before v6 show under the conclusion as read-only **Notes** (with "Add to conclusion" and "Remove") and print under the conclusion on the report. Marked regions (Annotate) stay on the chart and print in their own section.

## QBench upload

- **Retry without clearing the queue.** A failed report keeps its place, shows why it failed and has **Retry**; **Retry failed (N)** resends them all. Failed, skipped and stopped reports are no longer marked as sent.
- **Every failure says why** in the sheet (e.g. the sign-in file can't be read, no QBench API key, Chrome could not start, the lab ID isn't in QBench), and the full error goes to `app.log`. Before, every failure read "Upload returned false".
- The hub checks the QBench sign-in and API key before queueing and opens the password box when the sign-in file can't be read. `QBENCH_LOGIN_FILE` can point the hub at a local copy of the sign-in file.
- A retry sent while a stopped run was ending is no longer lost.

## Samples page

- **The chromatogram always draws** (or says why, with Retry). It no longer uses WebGL, which some browsers and remote-desktop sessions don't have, and opening a second sample or a live update no longer leaves the chart blank.
- **Checkboxes always match the selection.** Clicking a checkbox no longer leaves it showing the opposite of what is selected.
- **Stack chromatograms again.** **Add trace** puts ticked samples, comparison standards (e.g. Diesel #2, R99) or any lab ID on the open sample's chart, up to 8 traces. Switch between **Overlay** and **Stacked**; the legend names each trace with its own remove ×, plus Clear all. The set stays as you move between samples and survives a reload.
- Unreleased backfill rows say why they are backfill, and a held row's fix link now comes first, so a long review note can't hide it.

## Phones and tablets

- Every page works on a phone and a tablet in the same look: the sidebar opens as a drawer from a menu button, the top bar keeps the live status and notifications, sheets and dialogs rise from the bottom, and controls are big enough to tap.
- **Samples** shows the list or the sample one at a time below 900px, with "‹ Samples" to go back; tables scroll inside their card with the first columns held; charts resize on rotation.
- The desktop layout is unchanged.

## Smaller fixes

- Signing in through gc.asaplabs.net when the tunnel drops its https headers now says what's missing and what to check, and logs it.
- The Samples page's Results card no longer prints a stray "null" under the D86 switch, and a flaky Results test is fixed.
