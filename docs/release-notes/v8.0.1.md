**v8.0.1: QBench uploads when Chrome won't start, a steadier report queue, range names on narrow bands, and layout fixes.**

## Upgrading from v8.0.0

- Install as usual with Admin · Server > "Restart & install v8.0.1". No database change; rolling back is safe.

## Fixes

- **QBench upload "Chrome could not start: session not created".** On ASAPSV1 the full reason was "cannot find Chrome binary": chromedriver could not find Chrome where it looks for the hub's account. The hub now finds Chrome itself: `QBENCH_CHROME` if that is set, then a copy installed for every user, then one installed for a single Windows user. If there is none, Selenium Manager downloads Chrome for Testing. Each upload starts with its own fresh profile folder. If the ChromeDriver found when the hub started can't open Chrome, the hub tries once more with a driver that matches the installed Chrome. When Chrome still won't start, the queue shows the whole reason.
- **The report queue keeps one height.** The list and the upload progress scroll inside the sheet. The message line and the buttons stay at the bottom, so a long reason doesn't make the sheet taller. Download all keeps its label and shows its progress on the message line, so the buttons no longer move. The extra Close button is gone; use ✕ or Escape.
- **Narrow range bands on the report show the range's name.** A band too narrow for "Bio C19–C21" now shows "Bio". It falls back to its number only when the name doesn't fit either.
- **Compare's side column no longer scrolls sideways.** The Conclusion header wraps, so Edit stays in view while you edit.
- **The collapsed sidebar's footer is one centred column.** It shows the GC count as "1/2" instead of a second green dot beside the Live dot.
- **Add to queue opens the report sheet.** Like Export report, it now opens the sheet where you can set the standard and title and pick other standards to draw. It's titled "Add to report queue", and its main button adds the report to the queue. Download PDF is still there too.
- **No conclusion box in that sheet.** The conclusion is edited on Compare only. The sheet says which one the report will print: your edited text or the generated one.
