**v8.0.0: findings and conclusions in plain words.** The report's findings and the automatic conclusion are now short and written for the customer. This is a MAJOR release because the report's wording changes; nothing is calculated differently.

## Upgrading from v7.0.0

- Install as usual with Admin · Server > "Restart & install v8.0.0".
- **No database change.** Rolling back to v7.0.0 is safe.
- Reports already sent keep their wording. A conclusion you edited by hand is printed as you wrote it.

## What changed

- **Findings are one short line per range**, e.g. "Gas (C5–C11): higher than Diesel #2 — moderate". No retention times, peak sizes or percentages; the charts show those.
  - Both directions: "both higher and lower than Diesel #2". Sharp peaks: "2 sharp peaks above Diesel #2", or "…, plus 2 sharp peaks" after a broad difference.
  - A range only partly inside the run reads "(C5–C11, partly checked)"; one entirely outside it reads "not checked, outside this run".
  - No difference: "No differences found."
- **The conclusion is a few plain sentences**: what is different, then what it could mean. For example: "Compared to Diesel #2, this sample has more light material in the gas range. This could mean a lighter fuel, such as gasoline, was mixed in. This is a screening result only. It does not prove what is in the sample."
  - "slightly more", "more" and "much more" follow the finding's severity.
  - At most three ranges are written out; any more are pointed to the findings.
  - Sharp peaks: "It also has 2 sharp peaks above Diesel #2. These could be something added."
- Each finding's severity tag (marginal / moderate / significant) and the higher/lower/mixed verdict are unchanged from v7, and the conclusion still always agrees with the findings.
