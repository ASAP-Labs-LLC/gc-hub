**v8.1.1: "Bio" named on the report charts, comparison standards rename and delete properly, and a report queue that shows many reports at once.**

## Upgrading from v8.1.0

- Install as usual with Admin · Server > "Restart & install v8.1.1". No database change; rolling back is safe.

## Fixes

- **The report charts name "Bio" again, not "3".** The lab's ranges are listed Lighter C5–C11, Heavier C22–C44, Bio C19–C21. On the chart, Bio sits to the left of Heavier. The report placed the range labels in list order. Once "Heavier C22–C44" was placed, the space before it counted as used, so Bio printed as its number "3", and the footer read "(3) Bio C19–C21". Labels are now placed left to right across the chart, whatever order the ranges are listed in. A band too narrow for any name still shows its range number. The findings and conclusions don't change.
- **Renaming a comparison standard keeps one entry and its GC.** Before, the old name stayed in Settings marked "The file is missing from the standards folder", and the new name appeared beside it with no GC.
- **Deleting a comparison standard takes it off the list.** Before, it stayed listed as "missing", and pressing Delete again said it was not found.
- **Removing old leftover entries.** Entries left behind by earlier renames and deletes can now be removed with **Delete**. They show as "The file is missing from the standards folder". After an old rename, check the GC of the standard under its new name: before this fix it came back with no GC.
- **The report queue shows many reports at once.** Each report used to fill about a third of the sheet, because its buttons squeezed the text into a narrow column. Now each report takes:
  - one line for the lab ID and what it's compared with,
  - one line for its ranges (all of them on hover),
  - when the open Compare view has changed since the report was added, a short note with **Update** beside it.

  The sheet is also wider and taller (it was never as wide as intended). About ten reports fit at once on a 1440×900 screen and seven or more on 1366×768. Phones keep the full-width sheet.
