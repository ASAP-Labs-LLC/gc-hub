**v6.0.1: a better way to add conclusion presets.** A PATCH release: only how presets are picked on Compare changes. No result, report or export changes, and no database change (rolling back to v6.0.0 is safe).

- **Presets sit under the conclusion editor**, not in a menu over the text they go into. **Add preset** next to Edit opens the editor with the presets below it, so the conclusion stays in view while you pick.
- Each preset is a chip: click it to add its text at the cursor (or at the end). **Undo** takes the last one back.
- A preset already in the conclusion shows a ✓; clicking it shows you where it is instead of adding it twice.
- A preset that would push the conclusion past 1,500 characters is marked, and clicking it says why.
- With more than six presets, a **Filter presets** box appears.
- On a phone the chips are full-width and easy to tap.
