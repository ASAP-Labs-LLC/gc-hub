Setup checklist

Agent

The small program on the GC's computer that sends each finished run here. Its status updates by itself.

Calibration

Which n-alkane peak is which carbon number. D2887 needs this before any result is final.

Correction factors

Added to the reported D86 temperatures (°C). Never enter them in LEM as well: they would apply twice.

Results file

Final results are appended to this file, which LEM reads. Until the GC is live, runs are backfill and wait here until you release them.

Methods

Only mapped ChemStation methods are processed. A run is never guessed into D2887.

Backfill

Runs from before this GC went live. They are never written to the results file unless you release them.

Conflicts

The same sample arriving as a different file. Replacing keeps the old file.
