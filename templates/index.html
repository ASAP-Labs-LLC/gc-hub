          Sample Flag Rules
          
        
    
        
    
        
    “Above” flags when any point inside the time window exceeds the threshold (e.g. early high signal). “Below” flags when the signal stays under the threshold for the whole window (e.g. no signal). Matched samples get a tag in the rule’s color in all sample lists.
    
      
    

      
      
    
        Fuel-Type Best Fit
        
    
          
          
        
    
        
    
          
          
        
    
        
    
          
          
        
    
        
    
          
          
        
    
        
    Each parsed sample is compared to every comparison standard (amplitude-normalized, small retention shifts allowed). A score at or above the threshold names the fuel; otherwise a two-component blend is tried (“Mix: A + B (80/20)”), else the sample is labeled “Mix”. Results are written to the CSV and shown in sample lists.
    
      
    

      
      
    
        
    
          Sample library
          
        
    
        
    Re-reads each sample's run time from its CDF and re-sorts the library into true chronological (run) order. Runs in the background; results appear in notifications. Does not change distillation results.

      Help — GC Viewer & Distillation Parser
      
      
    
      
    
      
      
      Dashboard — Click a sample in the library to view its chromatogram, distillation curve, and D86/D2887 data side-by-side. Right-click a sample to set it as a comparison standard.
      
      
      Chromatograms (Advanced) — Double-click CDF files to overlay multiple chromatograms. Use the trace bar below the chart to toggle individual traces on/off.
      
      
      Distillation Data (Advanced) — Browse the full distillation results table. Click column headers to sort. Use the search bar to filter rows.
      
      
      Distillation Curve (Advanced) — Click samples to overlay their distillation curves for visual comparison.
      
      
      Analysis — Select a sample and comparison standards, adjust trend parameters and thresholds, then click Run Analysis. The trend and difference plots show deviations from expected baselines. The deviation report summarizes findings. Use the queue to batch multiple analyses for QBench export.
      
      
      Scan & Parse — Scans the watch folder for new CDF files, copies them to the processed folder, parses chromatographic data, and calculates D2887/D86 distillation temperatures.
      
      
      Corrected D86 — When checked, applies EQM correction factors from the configured JSON file to D86 distillation values.
