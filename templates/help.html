The GC Hub collects every run from the lab's gas chromatographs, works out its simulated distillation (ASTM D2887) and the matching D86 temperatures, and writes each final result to the file LEM reads. Nothing here needs a refresh: new runs and changes appear by themselves.

Samples

Pick a run to see its chromatogram, its results and how it compares with a standard. The list is newest first, grouped by day; you can sort it by lab ID instead.

Every run has its own link. Copy link gives an address anyone signed in can open, on the lab network or from anywhere. Other apps link to a lab ID with /lab/<lab ID>, which opens its newest run.

What the marks mean

  • Final: the result is done and written to the results file.
  • Held: waiting for something, which the row names (the GC's calibration, its correction factors, or a method to map). It carries on by itself once that is set.
  • Error: the file could not be read or worked out; the row says why.
  • Processing: just arrived, being worked out now.

A run marked backfill came from before its GC went live. It is kept, but not written to the results file unless someone releases it on the GC's page.

Results

Results shows every run's D2887 and D86 temperatures side by side. Key points shows IBP, 10 %, 50 %, 90 % and FBP; All points shows every cut. Filters stay in the address, so you can bookmark or send a filtered view. Download CSV saves what the filters show, with every cut.

Tick up to six runs to draw their distillation curves on one chart. Each run's lab ID opens its full numbers.

Corrected D86

D86 temperatures are converted from D2887 (ASTM D86 Appendix X4). Corrected adds that GC's correction factors, set on its page under Instruments; these are the numbers in the results file. Turned off, you see the conversion before the factors.

Appendix X4 has no 40 % or 60 % equation, so those two are the midpoints of the 30/50 and 50/70 conversions. No correction factor applies to them; hover the number to see this.

These are approximations for screening, not an ASTM-certified distillation.

Compare and reports

Compare lays a run over a comparison standard (by default the best fit) and lists where it differs, range by range. Add comments or mark a region; they go into the report. Export a PDF, or add runs to the report queue to download them together or attach them to their QBench samples.

Admin changes

Changes that affect every result (calibration, correction factors, best fit and findings settings, standards) ask for the admin password. It is asked once and kept in that browser tab for 15 minutes, never saved. Settings shows which sections need it.

When something needs you

The bell at the bottom of the sidebar lists what the hub wants a person to see: a GC that stopped checking in, a results file it could not write, a job that failed. Each has a link to where it is fixed. Work in progress (imports, report downloads) shows just above it, under "Running now".

If something looks wrong, open Admin · Diagnostics and download the diagnostics file to send along. Esc closes any open menu or dialog.
